## 確定ルール

作成時に必ず守るもの。

### 基本情報
- 所属：佐倉リーグ
- 拠点：間野台小学校（千葉県佐倉市王子台2-18）
- チーム編成

  - Cチーム（4年以下）
  - Dチーム（3年以下）
- 通常の集合時間：9:00
- 通常の練習終了：16:00
- ユニフォーム：緑

### 書式

日付見出し → チーム見出し → 時系列の予定 → 注意事項、の順。
チームが複数ある日は、チームごとに1行空けて並べる。

```
{月}/{日}（{曜}）
🔻{チーム名}（{学年}）
　…{時刻}  {集合・移動}
　●{時刻} {予定}
　⚾️{時刻} {試合種別} vs{相手チーム}
　※{注意事項}
```

記号の使い分け：

| 記号 | 用途 |
|------|------|
| 🔻 | チーム見出し |
| … | 集合・移動 |
| ● | 予定・区切り |
| ⚾️ | 試合 |
| ※ | 注意事項・持ち物 |

細かい点：
- 各行は全角スペース1つ分インデントする
- 対戦相手は `vs内郷スターズ` のように**スペースを空けずに**続ける
- 終了時刻は `(終了16:00)` と半角カッコで文末に付ける
- 注意事項のカッコは全角 `（領収書保管）`
- 罫線・枠線は使わない。【お願い】のようなまとめ欄も作らない

### 定型の注意書き
- 遠征・試合の日：`※緑ユニフォーム、着替え・運動靴 忘れずに`
- 駐車料金がかかる日：`※駐車料金{金額}円（領収書保管）`
- 配車に制限がある日：`※台数制限{N}台`

### 遠征時の時刻の決め方
- 会場までの移動時間は**必ずWeb検索で確認**する
- 現地到着は**試合開始1時間前**が基本
- 低学年のため**15分以上の余裕を上乗せ**する
  → 現地到着目標＝試合開始の1時間15分前
- 集合から出発まで10分程度みておく
